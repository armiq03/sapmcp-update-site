# SAP MCP Plugin — Eclipse P2 Update Site

## 설치 방법

1. Eclipse → **Help → Install New Software → Add...**
2. Name: `SAP MCP Plugin`
3. Location: `https://raw.githubusercontent.com/armiq03/sapmcp-update-site/main/`
4. "SAP MCP Plugin" 체크 → Next → Finish
5. Eclipse 재시작
